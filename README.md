# Miral Store (متجر ميرال) 🚀

متجر إلكتروني متكامل مبني باستخدام **Laravel** مع دعم معمارية **Headless** والربط مع منصة **سلة (Salla)**.

## 🛠️ التقنيات المستخدمة (Stack)
* **Backend:** PHP 8.2+ / Laravel 11.x
* **Frontend:** Blade, Tailwind CSS, Vite
* **Database:** MariaDB / MySQL via Docker Compose
* **Package Manager:** `npm` (موصى به للبناء)
* **Integration:** Salla Merchant API & Webhooks
